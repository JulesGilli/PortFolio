Hello, Garden est un tower defense cosy dans un jardin enchanté. Les tourelles n'y font rien tant que tu ne les as pas programmées : tu tapes du vrai C# dans l'éditeur du jeu, et la tourelle l'exécute, ligne par ligne. Aucune expérience du code n'est nécessaire. Ça commence par une ligne, Shoot(); puis une ligne ne suffit plus. Boucles, conditions, objets, listes : chaque idée arrive quand le jardin en a besoin.

Les erreurs font partie du monde. Rien ne plante : une tourelle dont le code lève une exception est étourdie, et la partie continue. La ligne fautive s'allume, la console nomme la vraie exception, et le Canard pose la bonne question. Il ne donne jamais la réponse.

La démo gratuite contient le prologue (quatre courtes leçons et une première bataille), une run roguelite complète dans le potager, avec ses combats, sa boutique et ses patchs qui tordent les règles, jusqu'à la Reine des fourmis, et l'Arbre à sève, où l'on débloque la suite du C# entre deux runs : méthodes, objets, listes, dictionnaires. Six insectes, six problèmes : l'escargot est une fork bomb qui se dédouble quand on l'arrête, le cloporte une régression qui repart du terrier.

Le jeu complet ajoutera deux zones du jardin, la serre et les racines, plus de vingt insectes au total, et les niveaux de langage suivants : patterns, exceptions, classes. Il est prévu sur Steam. Je le développe seul.

Dans le jeu

  • 01Du vrai C# tapé dans le jeu, exécuté ligne par ligne par les tourelles.
  • 02Une exception n'arrête rien : la tourelle est étourdie, la console nomme l'erreur, le Canard pose la bonne question.
  • 03Démo : un prologue, une run roguelite complète jusqu'à la Reine des fourmis, six insectes.
  • 04L'Arbre à sève débloque le langage entre les runs : méthodes, objets, listes, dictionnaires.
  • 05Démo gratuite sur Windows, en français et en anglais. Jeu complet prévu sur Steam.
